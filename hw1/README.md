# 从零开始构建三层神经网络分类器，实现地表覆盖图像分类

## 作业目标

本作业基于 `EuroSAT_RGB` 数据集，使用**纯 NumPy 手写实现**一个三层神经网络分类器，对地表覆盖遥感图像进行多类别分类。这里的“三层神经网络”指：

1. 输入层
2. 隐藏层 1
3. 隐藏层 2
4. 输出层

其中真正参与参数学习的是三层全连接映射：

- `Linear(输入 -> 隐藏层1) + ReLU`
- `Linear(隐藏层1 -> 隐藏层2) + ReLU`
- `Linear(隐藏层2 -> 输出层) + Softmax`

## 本项目完成了什么

- 完成了 `EuroSAT_RGB` 数据集的遍历读取与类别映射
- 完成了图像缩放、展平、归一化等预处理流程
- 手写实现了三层 MLP 的前向传播
- 手写实现了 Softmax 交叉熵损失与反向传播
- 完成了小批量梯度下降训练
- 完成了按类别分层的数据集划分
- 完成了验证集最佳模型保存逻辑
- 完成了测试集评估、混淆矩阵导出、分类指标统计和样例预测导出

## 实现思路

### 1. 图像预处理

为了让纯 `NumPy` 训练在可接受时间内完成，同时保留基本纹理与颜色信息，采用如下处理策略：

- 将原始 `64x64` RGB 图像缩放到 `16x16`
- 保留 3 通道颜色信息
- 将图像展平为长度 `16 x 16 x 3 = 768` 的向量
- 将像素值归一化到 `[0, 1]`
- 使用训练集均值和标准差对训练/验证/测试集做标准化

这样做的原因：

- 如果直接使用 `64x64x3=12288` 维输入，纯手写 MLP 的参数量和训练成本较高
- `16x16` 在压缩输入维度的同时，仍能保留一部分地物结构和颜色特征
- 对于“从零开始实现神经网络”的课程作业，这种折中更适合手工实现和复现

### 2. 三层神经网络结构

本次实验采用如下网络结构：

- 输入维度：`768`
- 隐藏层 1：`256`
- 隐藏层 2：`128`
- 输出层：`10`

激活函数：

- 隐藏层使用 `ReLU`
- 输出层使用 `Softmax`

损失函数：

- 多分类交叉熵损失

参数初始化：

- 使用 He 初始化，适配 `ReLU`

### 3. 训练流程

训练流程如下：

1. 读取并预处理所有图像
2. 按类别分层划分训练/验证/测试集
3. 基于训练集统计均值和标准差
4. 初始化三层 MLP 参数
5. 采用 mini-batch 方式训练
6. 每个 epoch 后在验证集上评估
7. 保存验证集准确率最高时的模型参数
8. 用最佳模型在测试集上做最终评估

### 4. 为什么加入“最佳模型保存”

完整训练中可以看到，最后一轮不一定是最好的一轮。例如本实验中：

- 第 `19` 轮验证集准确率达到最高
- 第 `20` 轮验证集准确率反而下降

因此增加“验证集最佳模型”逻辑，可以避免把效果较差的最后一轮当成最终模型，从而让测试结果更稳定。

## 实验结果

最终使用验证集最优模型得到的结果如下：

- 最佳轮次：`19`
- 训练集准确率：`65.92%`
- 验证集准确率：`61.33%`
- 测试集准确率：`61.78%`
- 测试集损失：`1.0807`
- 宏平均 Precision：`61.45%`
- 宏平均 Recall：`61.84%`
- 宏平均 F1：`61.23%`

### 部分类别表现

表现较好的类别：

- `Industrial`: F1 = `0.8240`
- `SeaLake`: F1 = `0.7865`
- `Forest`: F1 = `0.7690`
- `Pasture`: F1 = `0.6834`

表现相对较弱的类别：

- `Highway`: F1 = `0.3526`
- `PermanentCrop`: F1 = `0.4762`
- `AnnualCrop`: F1 = `0.5275`
- `HerbaceousVegetation`: F1 = `0.5255`

这说明：

- 工业区、海湖、森林等场景的纹理和颜色差异更明显，MLP 更容易分开
- 公路、农作物、草本植被等类别之间存在较强相似性，纯全连接网络难以充分提取局部空间结构

## 如何运行

### 1. 安装依赖

建议在 `alpha312` 环境中安装依赖：

```bash
conda activate alpha312
conda install numpy pillow
```

如果使用 `pip` 安装失败，优先使用 `conda install`，因为当前机器上的 `pip` 源存在证书问题。

### 2. 运行完整训练

```bash
python train_mlp.py --epochs 20 --batch-size 512 --learning-rate 0.03 --image-size 16 --hidden-dim1 256 --hidden-dim2 128 --output-dir outputs_final
```

### 3. 运行小规模快速测试

```bash
python train_mlp.py --epochs 2 --max-per-class 100 --output-dir outputs_smoke
```

## 结论

本作业已经完成了一个**不依赖深度学习框架、仅使用 NumPy 手写实现的三层神经网络分类器**，并成功应用到 EuroSAT 地表覆盖图像分类任务中。

最终模型在测试集上达到 `61.78%` 的准确率，说明三层 MLP 已经能够学习到一定的地物类别差异。但由于其缺少卷积结构，无法很好利用图像的局部空间特征，因此在类别相似场景上的区分能力仍然有限。

- 提升输入分辨率

- 引入卷积网络与本方法做对比实验
