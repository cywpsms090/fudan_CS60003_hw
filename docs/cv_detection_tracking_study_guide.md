### 0.6 你最容易被问到的问题

Q：这个任务是不是目标检测？

> 是。第一步微调 YOLOv8s，就是典型目标检测任务。模型输出车辆类别、置信度和 Bounding Box。视频跟踪和越线计数是在目标检测基础上的扩展。

Q：为什么 mAP50 只有 0.457？

> 这个数据集类别较多，部分类别样本少，还有小目标、遮挡和密集车辆问题。mAP50-95 更严格，所以数值更低。本次目标是完成检测、跟踪和计数的完整流程，结果已经足够支持课程演示。

Q：为什么要用 Tracking ID？

> 因为同一辆车会出现在很多帧里。如果没有 ID，就容易重复计数。有了 ID 后，可以规定同一个 ID 只计数一次。

Q：为什么遮挡会 ID 跳变？

> 遮挡会让车辆短时间检测不到，轨迹连续性被破坏。车辆重新出现时，如果位置变化大或附近有相似车辆，跟踪器可能认为它是新目标，于是分配新 ID。

Q：为什么画忽略区域？

> 中央路牌是固定遮挡物，模型有时会误检为车辆。为了让视频展示和计数更稳定，我对固定路牌区域设置 ignore region，不参与绘制和计数。这属于针对固定场景的后处理。

## 2. 什么是计算机视觉

计算机视觉，Computer Vision，简称 CV，是让计算机理解图像和视频的技术。

在图像任务中，常见问题包括：

- 图像分类：判断整张图是什么，例如“这是一张猫的图片”。
- 目标检测：找出图中有哪些物体，并用框标出来，例如“这里有一辆车、一辆卡车”。
- 语义分割：判断每个像素属于什么类别。
- 实例分割：不仅知道像素类别，还区分不同个体。
- 目标跟踪：在视频中持续追踪同一个目标。

本作业主要涉及：

- 目标检测；
- 视频逐帧推理；
- 多目标跟踪；
- 越线计数。

## 3. 什么是目标检测

目标检测的输出通常包括三部分：

- Bounding Box：目标框，表示物体在图像中的位置。
- Class：类别，例如 truck、rickshaw、bicycle。
- Confidence：置信度，表示模型认为这个框是某类目标的可信程度。

例如，一辆车的检测结果可以理解为：

```text
类别: truck
置信度: 0.82
框坐标: x1=120, y1=80, x2=260, y2=180
```

这里的框坐标表示左上角和右下角的位置。

目标检测比图像分类更难，因为模型不仅要知道“图里有什么”，还要知道“它在哪里”。

## 4. 什么是单阶段检测模型

目标检测模型大致可以分为两类：

- 两阶段检测器：先找候选区域，再分类和回归框。例如 Faster R-CNN。
- 单阶段检测器：直接在图像上预测类别和框。例如 YOLO、SSD、RetinaNet。

YOLO 属于单阶段检测模型。

单阶段模型的特点：

- 推理速度快；
- 适合视频实时检测；
- 工程使用方便；
- 精度和速度之间可以通过模型大小权衡。

本作业要求使用 YOLOv8 或同类现代单阶段模型，所以我们选择 YOLOv8s。

## 5. YOLO 是什么

YOLO 的全称是 You Only Look Once，意思是模型只看一遍图像，就直接输出所有目标的位置和类别。

它的基本思想：

1. 输入一张图像。
2. 神经网络提取图像特征。
3. 在不同尺度上预测目标框、类别和置信度。
4. 通过后处理去掉重复框。

YOLO 适合本作业，因为道路视频需要一帧一帧处理，如果模型太慢，视频处理会很低效。

## 6. YOLOv8 是什么

YOLOv8 是 Ultralytics 提供的一代 YOLO 模型，支持：

- 目标检测；
- 图像分割；
- 姿态估计；
- 分类；
- 跟踪。

本作业使用的是 YOLOv8 的检测模型，并结合它的 tracking 功能做多目标跟踪。

YOLOv8 常见检测模型大小：

| 模型 | 特点 | 适合场景 |
| --- | --- | --- |
| YOLOv8n | 最小最快，精度较低 | 设备性能弱、快速验证 |
| YOLOv8s | 小模型，速度和精度较平衡 | 课程作业、普通部署 |
| YOLOv8m | 中等模型，精度更高 | GPU 资源较充足 |
| YOLOv8l | 大模型 | 更追求精度 |
| YOLOv8x | 最大模型 | 高性能 GPU、精度优先 |

本次选择 YOLOv8s，原因是：

- 权重大约 21 MB；
- 参数量约 1113 万；
- M4 Pro 本机可以训练；
- 速度和效果比较平衡；
- 对课程汇报足够清晰。

## 7. 什么是预训练和微调

预训练模型是已经在大规模数据集上训练过的模型。例如 YOLOv8s.pt 已经学到了一些通用视觉特征。

微调，Fine-tuning，是在自己的任务数据集上继续训练这个模型，让它更适合当前任务。

本作业的过程是：

```text
YOLOv8s 预训练模型
        ↓
Road Vehicle Images Dataset
        ↓
继续训练 30 个 epoch
        ↓
专属车辆检测模型 best.pt
```

为什么不从零训练？

因为从零训练需要大量数据和算力。使用预训练模型微调，可以更快收敛，也更适合课程作业。

## 8. 数据集是什么样的

本作业使用的是 Road Vehicle Images Dataset。

它是一个道路车辆目标检测数据集，包含图片和对应标注。

YOLO 格式的数据通常长这样：

```text
images/train/xxx.jpg
labels/train/xxx.txt
images/val/yyy.jpg
labels/val/yyy.txt
road_vehicle.yaml
```

每张图片对应一个 txt 标注文件。标注文件中的一行通常表示一个目标：

```text
class_id x_center y_center width height
```

注意，这里的坐标通常是归一化坐标，也就是范围在 0 到 1 之间。

例如：

```text
2 0.512 0.431 0.180 0.095
```

可以理解为：

- 类别编号是 2；
- 目标中心在图像宽度的 51.2%、高度的 43.1%；
- 框宽是图像宽度的 18.0%；
- 框高是图像高度的 9.5%。

## 9. 训练时模型学到了什么

训练目标不是让模型“背图片”，而是让模型学会：

- 什么视觉特征像车辆；
- 不同车辆类别之间有什么区别；
- 目标框应该放在哪里；
- 哪些预测是错误的。

训练过程中，模型会不断比较自己的预测和真实标注之间的差距，然后更新参数。

## 10. Epoch、Batch Size、Iteration 是什么

这些词经常会在汇报中被问到。

Epoch：

> 所有训练图片完整被模型看过一遍，叫一个 epoch。

本次训练了 30 个 epoch，意思是训练集被完整使用了 30 轮。

Batch Size：

> 每次送进模型训练的图片数量。

本机训练时 batch size 用得比较小，因为 M4 Pro 显存/统一内存和 MPS 后端不适合太大的 batch。

Iteration：

> 模型完成一次 batch 的前向传播和反向传播，叫一次 iteration。

三者关系可以粗略理解为：

```text
每个 epoch 的 iteration 数 ≈ 训练图片数 / batch size
```

## 11. Loss 是什么

Loss 是损失函数的值，用来衡量模型预测和真实标注之间的差距。

YOLO 训练中常见 loss：

- box loss：目标框位置预测误差。
- cls loss：类别预测误差。
- dfl loss：边界框分布相关误差。

正常训练过程中，loss 一般应该逐渐下降。

本次最后几轮训练 loss 已经明显低于刚开始，说明模型在逐步学习车辆检测任务。

## 12. Precision、Recall、mAP 是什么

这些是目标检测中最重要的评价指标。

Precision，精确率：

> 模型预测出来的目标中，有多少是真的。

如果 Precision 高，说明误检少。

Recall，召回率：

> 真实存在的目标中，有多少被模型找到了。

如果 Recall 高，说明漏检少。

mAP，mean Average Precision：

> 综合衡量检测框位置和类别预测效果的指标。

常见的两个指标：

- mAP50：IoU 阈值为 0.5 时的 mAP。
- mAP50-95：多个 IoU 阈值从 0.5 到 0.95 的平均，更严格。

本次训练结果：

```text
Precision: 0.609
Recall: 0.424
mAP50: 0.457
mAP50-95: 0.282
```

如何解释这个结果：

- 模型已经能识别常见车辆；
- mAP50-95 较低，说明严格定位和小类别识别还有提升空间；
- 数据集中类别较多，且部分类别样本很少，会拉低整体指标；
- 对课程作业中的视频检测、跟踪、计数演示是可用的。

## 13. IoU 是什么

IoU 的全称是 Intersection over Union，交并比。

它衡量预测框和真实框重叠得有多好：

```text
IoU = 两个框的重叠面积 / 两个框的并集面积
```

如果预测框和真实框完全重合，IoU = 1。

如果两个框完全不重叠，IoU = 0。

mAP50 中的 50 表示 IoU 阈值是 0.5。也就是说，预测框和真实框的 IoU 大于 0.5，通常才算检测正确。

## 14. 为什么 mAP 看起来不算高

这是一个可能被问到的问题。

原因主要有：

1. 数据集类别较多，有些类别样本很少。
2. 车辆目标大小差异大，有近处大车，也有远处小车。
3. 道路场景中容易出现遮挡、密集目标、模糊目标。
4. 本次选择的是 YOLOv8s，不是更大的 YOLOv8m/l/x。
5. 训练轮数 30 epoch 对课程作业足够，但不是极限调参。

汇报时可以这样说：

> 整体 mAP 不算特别高，主要和数据集类别不均衡、部分类别样本较少以及道路场景遮挡有关。但主流车辆类别的检测效果可以支持后续视频跟踪和越线计数演示。

## 15. 什么是视频目标检测

视频其实可以看成很多张连续图片。

视频检测的基本做法：

```text
视频
↓
拆成一帧一帧图像
↓
每一帧送入 YOLOv8
↓
得到每一帧的车辆框和类别
↓
把检测结果画回视频
```

如果只做检测，每一帧之间是独立的。模型知道这一帧有几辆车，但不知道上一帧和下一帧中的车是不是同一辆。

所以还需要目标跟踪。

## 16. 什么是多目标跟踪

多目标跟踪，Multi-Object Tracking，简称 MOT，是在视频中持续追踪多个目标。

跟踪输出除了检测框和类别，还会给每个目标一个 Tracking ID。

例如：

```text
Frame 1: car ID=3
Frame 2: car ID=3
Frame 3: car ID=3
```

如果同一辆车一直保持 ID=3，说明跟踪稳定。

如果遮挡后变成：

```text
Frame 1: car ID=3
Frame 2: car ID=3
Frame 3: car disappears
Frame 4: car ID=7
```

这就说明发生了 ID 跳变。

## 17. YOLOv8 Tracking 是怎么工作的

YOLOv8 的 tracking 功能通常是：

```text
检测器 + 跟踪器
```

检测器负责每帧找目标。

跟踪器负责把不同帧中的检测框关联起来，判断它们是不是同一个目标。

常用的关联依据包括：

- 目标框位置是否接近；
- 运动方向是否连续；
- 框大小变化是否合理；
- 置信度是否足够；
- 有些跟踪器还会利用外观特征。

本作业可以这样理解：

> YOLOv8 先检测每一帧的车辆，再通过 tracking 算法把连续帧中的同一辆车连接起来，并分配 Tracking ID。

## 18. 遮挡为什么会导致 ID 跳变

遮挡是多目标跟踪中最常见的问题。

例如车经过保安亭时：

```text
出现 → 被保安亭挡住 → 再出现
```

如果遮挡很短，跟踪器可能认为它还是同一辆车，保持原 ID。

如果遮挡时间较长，或者同时有其他车经过，跟踪器可能会丢失原轨迹，车辆重新出现时被当成新目标，于是分配新 ID。

ID 跳变的常见原因：

- 遮挡时间太长；
- 目标框连续几帧检测不到；
- 车辆密集交汇；
- 多辆车外观相似；
- 目标运动方向突然变化；
- 检测器置信度不稳定。

汇报时不要把 ID 跳变说成模型“错得很离谱”。更准确的说法是：

> 遮挡会导致目标在若干帧中无法被稳定检测，跟踪器缺少连续观测，因此可能重新分配 ID。

## 19. 什么是越线计数

越线计数是交通视频分析中常见任务。

基本思想：

1. 在画面中设定一条虚拟线。
2. 对每个 Tracking ID 记录中心点轨迹。
3. 判断同一个 ID 的中心点是否从线的一侧移动到另一侧。
4. 如果跨越了，就计数一次。

为什么要用 Tracking ID？

因为如果只看每一帧检测框，一辆车会在视频中出现很多帧，可能被重复计数。

使用 Tracking ID 后，可以规定：

```text
同一个 ID 只计数一次
```

这样就能避免同一辆车被重复统计。

## 23. 常见提问与回答

### Q1：为什么选 YOLOv8s？

回答：

> YOLOv8s 在速度和精度之间比较平衡。YOLOv8n 更快但精度较低，YOLOv8m/l/x 可能更准但训练开销更大。本次课程作业需要完成训练、视频推理和展示，YOLOv8s 权重大约 21 MB，本机也可以训练，所以比较合适。

### Q2：YOLOv8 是单阶段模型是什么意思？

回答：

> 单阶段检测模型是指它直接从图像中预测目标框和类别，不需要先生成候选区域再分类。因此速度较快，适合视频逐帧检测。

### Q3：mAP50 和 mAP50-95 有什么区别？

回答：

> mAP50 是在 IoU 阈值 0.5 下计算的检测精度，要求相对宽松。mAP50-95 是在多个 IoU 阈值上取平均，更严格，所以通常比 mAP50 低。

### Q4：为什么 mAP50-95 只有 0.282？

回答：

> 这个指标比较严格，不仅要求类别正确，还要求框位置非常准确。道路车辆数据中有远处小目标、遮挡、密集车辆和类别不均衡问题，都会影响结果。另外本次使用的是 YOLOv8s 和 30 个 epoch，目标是完成课程实验流程，而不是做极限调参。

### Q5：Precision 和 Recall 分别说明什么？

回答：

> Precision 说明模型预测出来的目标有多少是真的，主要反映误检情况。Recall 说明真实目标中有多少被模型找到了，主要反映漏检情况。

### Q6：Tracking ID 是怎么来的？

回答：

> 检测模型每帧输出车辆框，跟踪器再根据框的位置、运动连续性和匹配关系，把不同帧中的同一辆车关联起来，并分配一个 Tracking ID。

### Q7：为什么遮挡会导致 ID 跳变？

回答：

> 遮挡会让目标在几帧中检测不到，轨迹连续性被破坏。如果目标重新出现时位置变化较大，或者附近有相似车辆，跟踪器可能认为它是一个新目标，于是分配新的 ID。

### Q8：越线计数为什么需要跟踪？

回答：

> 如果只做检测，同一辆车会在很多帧中都被检测到，容易重复计数。跟踪后可以根据 Tracking ID 规定同一辆车只统计一次，因此计数更稳定。

### Q9：为什么不用原始 COCO 模型直接检测？

回答：

> COCO 预训练模型能检测一些通用车辆类别，但本作业要求使用 Road Vehicle Images Dataset 微调专属模型。这个数据集里有 rickshaw、auto rickshaw、army vehicle 等更细的道路车辆类别，微调后更贴合任务。

### Q10：A100 有必要吗？

回答：

> 对大模型、高分辨率或大量 epoch，A100 会明显更快。但本次 YOLOv8s 规模较小，本机 M4 Pro 已经完成训练，用了约 3.67 小时，所以课程作业场景下本机足够。

### Q11：为什么视频里有的类别看起来不准？

回答：

> 这是因为数据集车辆类别比较细，例如 truck、minibus、auto rickshaw、policecar 等，部分类别外观相似，视频中还有遮挡和运动模糊，所以单帧类别可能不完全准确。但本作业重点是完成检测、跟踪和计数流程，只要车辆目标能够稳定检测并产生轨迹，就可以支持后续分析。

### Q12：为什么中央路牌要设置 ignore region？

回答：

> 中央路牌是固定背景物体，模型偶尔会把它误检为车辆。它不是我们关心的道路运动目标，所以我在后处理中设置固定忽略区域，把该区域中的检测结果排除，避免影响展示和越线计数。

### Q13：ByteTrack 是什么？

回答：

> ByteTrack 是一种多目标跟踪算法。它不是重新检测目标，而是把不同帧中的检测框进行关联，判断它们是否属于同一个目标，并为目标维护 Tracking ID。

### Q14：越线计数为什么用中心点？

回答：

> 检测框会随车辆大小和遮挡变化而变化，但中心点可以比较稳定地表示车辆位置。只要同一个 Tracking ID 的中心点从虚拟线一侧移动到另一侧，就可以认为该目标完成一次越线。

### Q15：如果 Tracking ID 跳变，会不会影响计数？

回答：

> 会有影响。如果同一辆车遮挡后变成新的 ID，可能导致重复计数；如果目标丢失，也可能漏计。因此越线计数依赖检测和跟踪稳定性。我的视频中最终统计为 22，这是基于当前检测和跟踪结果得到的实验统计值。

### Q16：本实验有什么不足？

回答：

> 第一，数据集类别不均衡，部分小类别样本少；第二，视频中存在固定遮挡物和绿化遮挡，会造成误检或漏检；第三，车辆密集或遮挡较重时 Tracking ID 可能跳变。后续可以增加数据、使用更大模型、提高输入分辨率或调整跟踪器参数。

## 24. 汇报时要避免的说法

不要说：

> YOLOv8 会自动理解视频中的车辆身份。

更准确：

> YOLOv8 负责检测每一帧中的车辆，tracking 算法负责把连续帧中的目标关联起来。

不要说：

> mAP 不高说明模型没训练好。

更准确：

> mAP 受到类别不均衡、小目标、遮挡和模型规模影响。本次结果可以支持检测跟踪流程展示，但仍有提升空间。

不要说：

> 只要有遮挡就一定会 ID 跳变。

更准确：

> 遮挡会增加 ID 跳变风险，但短时间遮挡时跟踪器也可能保持原 ID。

不要说：

> 越线计数就是看有几个检测框。

更准确：

> 越线计数需要结合 Tracking ID 和目标中心点轨迹，判断同一个目标是否跨过虚拟线。

## 28. 你应该如何理解这两份作业

这两份作业可以按一条学习路线理解。

HW1 是基础神经网络分类：

```text
图像 → 展平成向量 → 三层 MLP → Softmax 分类
```

它让你理解神经网络训练的基本流程：

```text
前向传播 → loss → 反向传播 → 参数更新
```

HW2 是现代计算机视觉视频分析：

```text
图像/视频帧 → YOLOv8 检测 → ByteTrack 跟踪 → 越线计数
```

它可以按三层理解。

第一层，检测：

> 给模型一张图，模型找出车在哪里。

第二层，跟踪：

> 给模型一段视频，模型不仅找车，还尽量判断连续帧中是不是同一辆车。

第三层，计数：

> 有了同一辆车的 ID 和轨迹之后，就可以判断它是否经过某条线。

所以，这不是单纯“跑了一个模型”，而是一个完整的视频分析流程：

```text
检测结果 → 跟踪 ID → 轨迹 → 遮挡分析与越线计数
```

你汇报时只要抓住这条主线，就不会乱：HW1 讲基础训练流程，HW2 讲检测、跟踪和计数的实际应用。
